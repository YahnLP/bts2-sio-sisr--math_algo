# S03 – Suites géométriques

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – mathématiques approfondies et algorithmique |
| **Séance** | S03 (séance 3 sur 19) – Phase 1 |
| **Durée** | 4 heures |
| **Chapitre du programme** | Suites numériques – suites géométriques (proposé, à valider) |
| **Prérequis** | S02 |
| **Outils** | Papier, calculatrice, éditeur Python intégré au site |

> [!NOTE]
> **Question qui guide la séance :** *« Quand une grandeur est multipliée à chaque étape, comment prévoir sa valeur et la somme cumulée ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Reconnaître une suite géométrique et déterminer sa raison
2. Écrire le terme général
3. Calculer la somme de termes consécutifs
4. Modéliser une croissance exponentielle (doublement, taux)
5. Programmer et tester une suite géométrique
