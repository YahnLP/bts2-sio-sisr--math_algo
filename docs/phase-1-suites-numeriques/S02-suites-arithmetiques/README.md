## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Reconnaître une suite arithmétique et déterminer sa raison
2. Écrire le terme général
3. Calculer la somme de termes consécutifs
4. Modéliser une croissance linéaire (stockage, tarifs)
5. Programmer et tester une suite arithmétique
