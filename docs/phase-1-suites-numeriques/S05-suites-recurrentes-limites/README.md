> [!NOTE]
> **Question qui guide la séance :** *« À partir de quand une grandeur dépasse-t-elle un seuil, et vers quoi tend-elle ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Étudier la monotonie d'une suite
2. Déterminer la limite d'une suite géométrique
3. Étudier une suite récurrente d'ordre 1 (point fixe)
4. Écrire un algorithme de seuil
5. Interpréter une limite dans le contexte
