## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Calculer des intérêts simples et composés
2. Calculer un amortissement de dette par mensualités constantes
3. Prévoir l'évolution d'un volume de données
4. Choisir le bon modèle (arithmétique ou géométrique)
5. Écrire une fonction de simulation et la tester
