> [!NOTE]
> **Question qui guide la séance :** *« Quelle structure de données choisir pour ranger et retrouver l'information ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Utiliser une pile et une file
2. Utiliser un dictionnaire
3. Choisir une structure selon l'usage
4. Évaluer le coût des opérations
5. Programmer des cas d'usage réseau (journaux, files d'attente)
