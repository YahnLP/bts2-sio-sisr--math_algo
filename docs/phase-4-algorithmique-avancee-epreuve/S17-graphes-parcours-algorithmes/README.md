## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Représenter un graphe en Python
2. Écrire un parcours en largeur
3. Écrire l'algorithme de Dijkstra
4. Évaluer la complexité
5. Tester sur un réseau
