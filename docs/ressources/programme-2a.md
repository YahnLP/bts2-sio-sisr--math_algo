# Programme de la 2e année

> [!WARNING]
> **Contenu proposé par l'enseignant, à valider.** Le site de 1re année couvre le programme obligatoire de l'épreuve de mathématiques pour l'informatique et **exclut** la récursivité, l'analyse d'algorithme et les suites numériques. Cette 2e année propose d'**approfondir** ces notions. Le programme officiel détaillé (arrêté du 4 juin 2013 pour les mathématiques) **n'a pas été relu pour ce site** : le rattachement de chaque séance à un chapitre est une proposition, à confronter au texte officiel.

## Principe

Quatre phases, 19 séances de 4 h, dans le même format qu'en 1re année : fiche, cours, exercices, TP Python avec tests automatiques, aide-mémoire. Les corrigés sont hors du site.

## Répartition

| Phase | Séances | Contenu |
|---|---|---|
| 1 | S01 à S05 | Suites numériques : définition, arithmétiques, géométriques, applications, limites |
| 2 | S06 à S10 | Récursivité : principe, pile d'appels, tableaux, diviser pour régner, arbres |
| 3 | S11 à S15 | Analyse d'algorithmes : terminaison, coût, complexité, tris, mesures |
| 4 | S16 à S19 | Structures de données, graphes en Python, méthode, épreuve blanche |
