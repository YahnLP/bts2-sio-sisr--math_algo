# S15 – Mesurer et connaître les limites

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – mathématiques approfondies et algorithmique |
| **Séance** | S15 (séance 15 sur 19) – Phase 3 |
| **Durée** | 4 heures |
| **Chapitre du programme** | Analyse d'algorithme – mesures, limites (proposé, à valider) |
| **Prérequis** | S13 ; S14 |
| **Outils** | Papier, calculatrice, éditeur Python intégré au site |

> [!NOTE]
> **Question qui guide la séance :** *« Que faire quand un algorithme devient trop long, même pour un ordinateur ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Mesurer un temps d'exécution
2. Relier la mesure à la complexité
3. Reconnaître une explosion exponentielle
4. Estimer la durée d'une recherche exhaustive
5. Proposer une amélioration
