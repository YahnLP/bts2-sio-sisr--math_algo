> [!NOTE]
> **Question qui guide la séance :** *« Combien d'opérations un algorithme effectue-t-il, selon la taille des données ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Choisir une opération de référence
2. Compter les opérations dans une boucle simple
3. Compter dans deux boucles imbriquées
4. Distinguer meilleur cas et pire cas
5. Compter par programme avec un compteur
