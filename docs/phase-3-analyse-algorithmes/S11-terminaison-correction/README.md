# S11 – Terminaison et correction d'un algorithme

| Élément | Détail |
|---|---|
| **Niveau** | BTS SIO option SISR, 2e année – mathématiques approfondies et algorithmique |
| **Séance** | S11 (séance 11 sur 19) – Phase 3 |
| **Durée** | 4 heures |
| **Chapitre du programme** | Analyse d'algorithme – terminaison, correction (proposé, à valider) |
| **Prérequis** | S10 |
| **Outils** | Papier, calculatrice, éditeur Python intégré au site |

> [!NOTE]
> **Question qui guide la séance :** *« Comment prouver qu'un algorithme s'arrête et fait ce qu'on veut ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Trouver un variant de boucle
2. Énoncer un invariant
3. Prouver la correction d'une boucle simple
4. Écrire des tests pertinents
5. Repérer les cas limites
