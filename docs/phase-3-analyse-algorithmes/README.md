# Phase 3 – Analyse d'algorithmes

**Séances S11 à S15.** Terminaison et correction, coût en opérations, complexité asymptotique, comparaison des tris et des recherches, mesures.

> [!NOTE]
> Chaque séance de 4 h contient une **fiche séance**, un **cours**, des **exercices**, un **TP Python** et un **aide-mémoire**. Les séances marquées *à valider* attendent la relecture de l'enseignant.
