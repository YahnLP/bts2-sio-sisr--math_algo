| **Outils** | Papier, calculatrice, éditeur Python intégré au site |

> [!NOTE]
> **Question qui guide la séance :** *« Comment comparer deux algorithmes quand les données deviennent très grandes ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Définir la notation O
2. Classer les complexités usuelles
3. Simplifier une expression de coût
4. Comparer deux algorithmes
5. Interpréter un ordre de grandeur
