> [!NOTE]
> **Question qui guide la séance :** *« Quel tri ou quelle recherche choisir selon les données ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Écrire le tri par sélection et le tri par insertion
2. Comparer leur coût
3. Comparer recherche séquentielle et dichotomique
4. Comparer avec le tri fusion
5. Choisir selon le contexte
