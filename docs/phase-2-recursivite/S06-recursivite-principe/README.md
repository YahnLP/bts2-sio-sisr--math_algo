## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Identifier le cas de base et le cas récursif
2. Écrire une fonction récursive simple
3. Dérouler une exécution récursive
4. Justifier la terminaison par un variant
5. Comparer avec une version itérative
