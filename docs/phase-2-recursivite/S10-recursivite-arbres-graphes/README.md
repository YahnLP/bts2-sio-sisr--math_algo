> [!NOTE]
> **Question qui guide la séance :** *« Comment parcourir un dossier contenant des sous-dossiers, ou un graphe, sans se perdre ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Représenter une arborescence en Python
2. Parcourir récursivement une arborescence
3. Calculer taille et profondeur
4. Écrire un parcours en profondeur de graphe
5. Éviter les cycles
