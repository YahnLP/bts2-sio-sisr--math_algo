> [!NOTE]
> **Question qui guide la séance :** *« Comment résoudre un problème en le coupant en deux et en recollant les résultats ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Décrire le principe diviser pour régner
2. Écrire la recherche dichotomique récursive
3. Écrire l'exponentiation rapide
4. Écrire le tri fusion
5. Estimer le nombre d'appels
