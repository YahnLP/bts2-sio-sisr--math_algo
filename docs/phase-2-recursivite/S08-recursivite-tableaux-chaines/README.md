> [!NOTE]
> **Question qui guide la séance :** *« Comment traiter une liste ou un texte en le réduisant d'un élément à chaque appel ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Parcourir récursivement une liste
2. Traiter une chaîne récursivement (palindrome, inversion)
3. Écrire une recherche récursive
4. Calculer somme, maximum, comptage récursivement
5. Repérer les copies coûteuses
